MYSHELTER — Comprehensive Technical & Deployment Report

Target: Vercel Serverless + Supabase | Status: Ready for Production Deployment Generated: October 2026

1. Executive Summary & Architecture Overview

MYSHELTER is a production-engineered hotel-booking platform tailored for the Delhi, Noida, and Ghaziabad metropolitan area. It features a high-performance vanilla frontend paired with an elastic serverless Node.js backend hosted natively on Vercel and backed by a managed Supabase PostgreSQL instance.

Frontend Architecture
  • Framework: Vanilla HTML5, CSS3, Modern ES6+ JavaScript.
  • Design System: Custom "Haven" warm earthy palette with responsive grid, accessible touch targets, and zero bloated runtime UI frameworks.
  • Room Inventory: 141 curated rooms across Delhi (52), Noida (44), and Ghaziabad (45).
  • Build Artifact: Static distribution compiled to dist/ via scripts/build.js.
Backend & Data Architecture
  • Compute: Vercel Serverless Functions running under api/* (Node.js runtime).
  • Database: Supabase PostgreSQL (users, bookings, preferences, otp_codes).
  • Authentication: Native crypto.scrypt password hashing with HMAC-SHA256 JWT tokens.
  • Zero Dependency Serverless: Core functions rely purely on native Node standard library modules.

5. Step-by-Step Vercel Deployment Guide

Step 1: Import GitHub Repository

Log in to vercel.com → Click "Add New..." → "Project" → Select the MYSHELTER repository from your GitHub account.

Step 2: Configure Project Settings
  • Framework Preset: Choose Other.
  • Root Directory: ./ (Leave default).
  • Build & Output Settings: Toggle "Override" for Output Directory and set to dist. Build Command is npm run build.
Step 3: Populate Environment Variables

Expand the Environment Variables tab and add SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, ADMIN_PASSWORD, and JWT_SECRET for Production, Preview, and Development scopes.

Step 4: Deploy & Verify

Click "Deploy". Vercel will clone the repo, run npm install, execute npm run build, and automatically expose serverless endpoints under /api/*.
